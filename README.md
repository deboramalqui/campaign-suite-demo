# Campaign Suite — interactive sample prototype

**Live demo:** https://deboramalqui.github.io/campaign-suite-demo/

A sample prototype made for a CV. Styled with the brand tokens of **Kol Accesorios** (an Argentine phone-accessories retail chain) for the demo. **Every number, name and campaign is invented.** It connects to no account and cannot spend money.

It models a reporting and campaign-planning workspace for the people who pay for ads, built around one question: *did it work, and what did it cost?*

## What you can try
1. **Today** — spend, goal, result and cost per result for each running campaign, judged against like-for-like campaigns; an editable gross-margin assumption; a purchase funnel.
2. **Campaigns** — current and past campaigns, grouped by result type, status or platform, with peer comparison.
3. **New campaign** — pick a post, a required goal, several cities with radius, followers or not, remarketing groups, budget and dates; checks, review and approval, then "created paused" (simulated).
4. **Data checks** — three typical data problems (one lead counted five times, a tag firing in a loop, mixed time windows) with a before/after switch.

## About
Concept and product rules by Débora Malqui, based on a real project she led. Built with AI-assisted development. A single static file (`index.html`): no build step, no dependencies beyond Google Fonts.
